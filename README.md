## Changelog

### Version 3.0 – Part 3 Update

**Interactive Elements:**
- Added a Leaflet interactive map to locations.html showing all three branches. (Leaflet, 2026)
- Added a lightbox gallery to gallery.html – click any image to view it larger.
- Added an accordion to faq.html – click a question to reveal the answer.
- Added a modal to products.html – click "Details" on any product to see more info.
- Added CSS animations: fade-in on scroll, button hover lifts, smooth transitions.

**SEO:**
- Added structured data (JSON-LD) to the homepage for local business.
- Added canonical URLs to prevent duplicate content.
- Added Open Graph and Twitter Card tags for social sharing.
- Optimised images with loading="lazy" and descriptive alt text.
- Added page speed improvements (async font loading, deferred JS).

**Security:**
- Added rel="noopener noreferrer" to all external links.
- Added basic browser security headers (X-Content-Type-Options, referrer policy).
- Added input sanitisation on all forms (trim + regex patterns).

**Forms:**
- Confirmed both enquiry.html and contact.html meet the brief.
- Added character counters to textareas.

### Version 2.0 – Part 2 Update

- Moved all inline styles to external stylesheet (css/style.css).
- Added CSS reset.
- Set up base styles and responsive design.
- Fixed mobile hamburger menu.
- Added JS product array with dynamic rendering.
- Added search bar and sort dropdown to products page.
- Added title tags, meta descriptions, alt text, robots.txt, sitemap.xml.
- Added JS form validation to both enquiry and contact forms.

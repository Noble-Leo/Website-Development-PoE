## Changelog

### Version 2.0 – Part 2 Update

**CSS and Styling:**
- Moved all inline styles to external stylesheet (css/style.css)
- Added CSS reset for consistent rendering across browsers
- Set up base styles: font family, colours, spacing
- Added responsive design with three breakpoints (992px, 768px, 480px)
- Fixed mobile hamburger menu so it works on all pages

**Dynamic Content:**
- Products now load from a JavaScript array instead of hard-coded HTML
- Added search bar to filter products by name or description
- Added sort dropdown for price and name

**SEO:**
- Unique title tags and meta descriptions on every page
- Descriptive alt text on all images
- Proper heading structure (one H1 per page)
- Created robots.txt and sitemap.xml

**Forms:**
- enquiry.html: validates input, shows response with cost info
- contact.html: validates input, compiles message into email
- Added JavaScript validation with error messages

**General:**
- Cleaned up HTML indentation
- Updated social media links
